title: Lookup users to add as contacts
excerpt: >-
  Searches for users in the caller's tenant that can be added as contacts.

  Excludes the caller and users who are already contacts.

  Supports filtering by first_name, last_name, username, email, phone_number,
  wallet_address, user_id, and free-text search (q).
